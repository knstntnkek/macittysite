# Keyboard shortcuts

## Sessions &amp; library

| Shortcut | Action |
|---|---|
| `⌘N` | New connection |
| `⌘⇧L` | Show saved sessions |
| `⌘D` | Duplicate selected session |
| `⌘K` | Focus the sidebar search |
| `⌘↩` | Connect (or switch to the live terminal) |

## Terminal

| Shortcut | Action |
|---|---|
| `⌘F` | Open the find bar |
| `⌘⇧F` | Close the find bar |
| `⌘G` | Next match |
| `⌘⇧G` | Previous match |
| `⌘E` | Use selection for find |

## Panes (split view)

| Shortcut | Action |
|---|---|
| `⌘]` | Focus the other pane |
| `⌘[` | Focus the other pane back |

## App

| Shortcut | Action |
|---|---|
| `⌃⌘L` | Lock MaciTTY (when app lock is enabled) |
| `⌘,` | Settings |
| `⌘Q` | Quit — asks first if sessions are connected |

Plus the usual macOS editing keys in the terminal — `⌘C`/`⌘V` copy/paste,
`⌘A` select all — and standard shortcuts like `⌘W` and `⌘M` for windows.
