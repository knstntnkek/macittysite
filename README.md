# MaciTTY

A native macOS terminal client for SSH, Telnet, Rlogin and serial connections —
saved sessions, key management, tunnels and SFTP file transfer in a modern
Mac app. All data stays on your Mac: no accounts, no cloud sync, no telemetry.

- Universal build for Apple Silicon and Intel, macOS 14+
- Signed and notarized
- English, German, Russian and Spanish

**Download:** `MaciTTY-latest.dmg` right here in this repository — open it and
drag MaciTTY to Applications.

## Found a bug? Have an idea?

This repository is the place to report problems and request features.
[Open a new issue](../../issues/new) — no account beyond a GitHub login needed.

When reporting a bug, a few details help a lot:

- **macOS version** and whether you're on Apple Silicon or Intel
- **What you did** — steps to reproduce, e.g. "connected to X, opened Files pane, dragged a folder"
- **What happened vs. what you expected**
- **Screenshots or logs**, if relevant (blur anything private, like host names)

For feature requests, just describe what you'd like to be able to do —
real workflows make the best cases.
